# Sky Strike: MIG-16 Combat 🚀

This is a 3D tactical air combat simulator optimized to run directly within cloud-based environments such as **Google Colab**. The project features an 

adaptive full-screen rendering system and custom keyboard-mapped flight controls.

---

## 🛠️ How to Run the Code in Google Colab

Follow these simple steps to start the simulation:

### 1. Set Up the Environment
1. Open [Google Colab](https://colab.research.google.com/) using your Google account.
2. Create a **New Notebook**.

### 2. Copy and Inject the Code
1. Copy the entire source code from your game script file.
2. Paste the code into an empty code cell inside your Colab notebook.

### 3. Run the Simulator
1. Click the **Play** button (▶️) on the left side of the code cell, or press the `Ctrl + Enter` shortcut.
2. The game canvas will immediately render in the output area below the cell.

---

## 🎮 Flight Controls

To interact with the simulation, first click inside the game canvas to focus your keyboard input, then use the following keys:

* **Movement (X / Y Axes):** Use the **Arrow Keys** or the standard **W, A, S, D** configuration.
* **Numerical Precision:** Alternatively, you can use the Numpad keys: **8 (up), 2 (down), 4 (left), and 6 (right)**.
* **Weapon Systems:**
  * `SPACEBAR`: Simple Blaster Cannon (Basic yellow projectile).
  * `G`: Fast SMG Gun (Rapid dual orange stream).
  * `M`: Heavy Missile (Massive white projectile with an expanded hitbox).
* **System Reboot:** If your hull integrity collapses (HULL: 0%), press the `R` key to reset the simulation and start a new flight.

---

## 🖥️ Full-Screen Mode

The simulator features a responsive web container layout:
1. Upon loading, it automatically stretches to fill your current browser window proportions.
2. For a fully immersive experience, click the green **"🗖 PANTALLA COMPLETA"** (Full Screen) button located at the bottom-right corner of the interface.
3. You can exit this mode at any time by pressing the `ESC` key.
